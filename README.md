# 🏠 Home Expense & Saving Tracker — Frontend

A modern, responsive, and bilingual (Hindi/English) web interface for tracking household expenses and savings goals. Built using Expo / React Native Web and integrated with Google Identity Services (GSI) for seamless authentication.

---

## ✨ Features

- **Multilingual Onboarding:** Interactive welcome flow with instant Hindi/English language toggle.
- **Google Sign-In (GSI):** Secure, one-click user authentication.
- **Expense & Savings Dashboard:** Clean layout for tracking daily spendings, budget limits, and savings goals.
- **Responsive UI:** Fully optimized for mobile screens, tablets, and desktop browsers.

---

## 🛠️ Tech Stack

- **Framework:** Expo / React Native Web
- **UI & Styling:** Tailwind CSS / React Native StyleSheet
- **Icons & Assets:** Lucide React / Expo Vector Icons
- **Deployment:** Vercel
